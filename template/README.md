# Video project (content engine)

A video as a Remotion project that a human and Claude Code edit together. Created by the content engine
(`D:\code_files\content-engine`, see its README); packages, the pipeline and Blender tooling come from there.

```
npm run studio        # open the editor → http://localhost:3000
npm run render        # delivery render → out/video.mp4 (final plates, no guides)
npm run deliver       # loudness-normalised upload file → out/delivery.mp4
npm run render:draft  # half-res preview with cue readout + timecode burned in
npm run still -- out/f.png --frame=120     # one frame (any CLI flag works)
npm run stills        # contact sheet of the whole video → out/contact_sheet.png
npm run typecheck
```

## How the piece is built

| Layer | Where | Edit it |
|---|---|---|
| Format, plates, voice and music settings | `project.json` | by hand or ask Claude |
| Narration | `script.json` (one cue per sentence, scene titles, extra `pause` after a line) | edit, then `ce pipeline <project> vo` (records only missing lines) |
| Timing | `src/data/timing.json` | generated by `vo`; never by hand |
| Voice lines, music source | `audio/vo/*.wav`, `audio/music.mp3` | delete a line's WAV to re-record it |
| Stems, duck envelope | `public/audio/*.wav`, `src/data/duck.json` | `ce pipeline <project> stems` |
| Sound effects | `sfx.json` (events relative to cues) → `src/data/sfx_events.json`, `public/audio/sfx/` | `ce pipeline <project> sfx` |
| 3D plates | `blender/*.py` shots → `renders/<plate>/final` → `public/plates/<plate>_{final,draft}.mp4` | `ce blender <project> shot.py final`, then `ce pipeline <project> plates` |
| 3D → 2D tracking | `src/data/markers.json` | written by the shot script |
| 2D layer | `src/scenes/*.tsx` (this video) + `src/components`, `src/lib` (engine code, frozen copy) | code, or Default Props in Studio |
| Tweakables | `src/Root.tsx` → `defaultProps={{…}}` of the `Reel` composition, typed by `src/lib/schema.ts` + `src/scenes/schema.ts` | Studio: open `Reel`, Inspector → Default Props; edits save here by themselves |

Every animation is keyed to the second a narration cue starts (`cue("s03_cue", "response")`), so re-recording a line
moves everything with it. After re-timing, `ce pipeline <project> audio` rebuilds timing, stems, effects and captions
(no paid calls).

## Studio tour

- **Timeline** rows are named after the script: scenes, plates, `Voice`, `Music (ducked)`, `SFX · …`.
- **Default Props** (right sidebar, Inspector tab): visible when nothing in the timeline is selected (press Esc to
  deselect). Sections: `plates` (final/draft), `guides`, `theme`, `type`, `look`, `audio`, `scenes.sXX`.
  Headline lines use `*asterisks*` for italics. Edits save into `src/Root.tsx` by themselves; Ctrl+Z / Ctrl+Y undo and
  redo while Studio is open. (Selecting a timeline row shows that layer's Transform instead: leave it alone, it edits
  shared component code.)
- **Scenes folder** in the sidebar: each scene on its own, starting at frame 0, showing the saved props of `Reel`.
  Edit in `Reel`: the scene previews have no props editor.
- **Guides**: safe areas, baseline grid, tracked 3D markers, cue readout, timecode, captions. Always off in `npm run render`.

## Making it: the Brief

A new video starts on the engine's **Brief** tab. Claude (right) asks what you want to make and talks it through with
you; the board (left) fills in as decisions are made: idea (`brief.md`), script (`script.json`), look (`style.md`,
style frames in `brief/frames/`), sound (`project.json` → `voice`, `music`), visual plan (`plan.md`), references
(`references/`). When it's all agreed Claude shows the script and a few style frames and waits for **Approve and
build**; only then does it record the voice, make the music and render 3D drafts. `brief/status.json` holds the stage.
How Claude runs this is in `.claude/skills/make-video/SKILL.md`.

## Finishing it: the Final tab

The engine's **Final** tab runs the final render in the background (3D final frames, plate encoding, video, upload
file `out/delivery.mp4`), shows progress, survives closing the browser, and resumes where it stopped. If a step fails,
the error goes to Claude, who can fix it and resume. State and logs: `out/render/`.

## Sharing it: the Publish tab

The engine's **Publish** tab uploads `out/delivery.mp4` to YouTube (through its API, private by default) and hands
Facebook Page and Instagram posts to Claude, who prepares them in your Chrome and stops before Post. Drafts and
results: `publish/`.

## In the engine website

Open the video from the engine (`ce app`): Studio on the left, Claude Code on the right. Pause on a moment and talk
about it ("make *this* headline smaller", "the label here overlaps the brain"): every message tells Claude the time,
scene, narration line and the headlines on screen, and Claude can look at the frame, move the playhead and open the
setting it means in the props editor. `src/components/EngineBridge.tsx` does the reporting; it is inactive in renders.

## Working together

- `notes/NOTES.md` is the task list: add timestamped notes, Claude works through them and marks them done.
- Commit after each round so either side can diff or revert. `git log -p src/Root.tsx` shows every prop change.
- Don't hand-edit the props in `src/Root.tsx` while Studio is open; Studio and the editor would overwrite each other.
- Never `npm install` here: `node_modules` is a link to the engine's packages. If it breaks, run `ce link`.
