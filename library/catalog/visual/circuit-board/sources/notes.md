# Sources: Circuit Board

## Lemo-Opuscar, style No. 76 "Circuit Board"

- **Where:** github.com/lemomo-ai/lemo-opuscar, `styles/circuit-board/` (`STYLE.md`, `DEMO.md`, `style.json`,
  `demo/src/palette.js`, `demo/src/post.js`). Read through `docs/research/styles/five-skills.md`, section "Circuit
  Board". Nothing was downloaded for this style.
- **Licence:** MIT for code and docs; demo film and stills CC BY 4.0 (credit LemoLab). No code was copied; the source's
  `font.js` wasn't read. Noto Sans is SIL OFL.

### Taken from it
- All palette values and colour rules; the board's layers; pads, vias, weave; the routed-stroke idea for silkscreen;
  world-anchored plotted text; text kept out of the depth-of-field bands.
- Current told apart by motion, pad flashes, the camera vocabulary, matched cuts.
- The additive two-blur light layer, bands, key light, motes, vignette; the banned list.

### Proposed (not in the source)
- The stroke alphabet itself and its size rules; trace, pad and via sizes; grain 0.02; all sample scenes.

### Changed for vertical
- Routes run down the tall frame; labels at 44 px capitals and up; one Latin line on the subtitle plate at y = 1500; the
  bands sit inside the safe zones.
