# Hook formulas

Twenty-one ways to open a video. The names come from youtube-agent-skill (MIT); the notes are the engine's own. Use only
what's true of this video: a formula that needs a fact you don't have is the wrong formula.

| Formula | How it opens | Don't use it when |
|---|---|---|
| The Statistic | A surprising figure, stated plainly | the number needs explaining first |
| Someone Else's Result | What happened to a real person or company | there's no real case to name |
| The Mistake | The error most people make | it's a mistake nobody really makes |
| Contrarian Flip | The opposite of what people assume | the "common belief" is a straw man |
| The Reveal | Something hidden is about to be shown | the reveal can't match the build-up |
| The Superlative | The biggest, smallest, oldest or first of something | it can't be backed up |
| The Clock | How little time something takes, or how long it took | the time isn't the interesting part |
| I Tried It | A first-hand test and its outcome | nobody in the video tried it |
| The Question | A question the viewer can't answer but wants to | they could answer it, or don't care |
| Before and After | Two states, with the change between them unexplained | the change is small |
| The Teardown | Taking something familiar apart | the thing isn't familiar |
| The Stack | Several causes piling into one result | the causes don't connect |
| The Warning | Something the viewer is about to get wrong | the danger is made up |
| The List | A number of things, with the count up front | the items are padding |
| The Receipt | Proof shown first, explanation after | there's no proof to show |
| The Insider | How it really works, from inside | there's no inside view |
| The Impossible Claim | Something that sounds false but is true | it needs too much proof to believe |
| The Comparison | Two things side by side, one surprising | the gap is obvious |
| The Origin | Where something strange really came from | the origin is dull |
| The Deadline | Something ending or changing soon | nothing is really ending |
| The Direct Address | Speaks to one kind of person | it narrows the audience too far |
